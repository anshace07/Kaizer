# PlantPulse AI — frontend

Next.js (App Router, TypeScript) + Tailwind + shadcn/ui. Talks to the FastAPI backend at
`http://localhost:8000` (override with `NEXT_PUBLIC_API_URL`). See the root `README.md` to run it.

- `src/app/` — one folder per page (dashboard, report, incidents, incidents/[id], handover, performance)
- `src/components/` — sidebar, footer, badges, incidents table; `ui/` is generated by shadcn
- `src/lib/api.ts` — every backend call; `format.ts` — labels/dates/shift; `use-auto-refresh.ts` — 5 s polling
